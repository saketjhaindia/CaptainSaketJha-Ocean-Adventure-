# Captain Saket Jha: Ocean Adventure

A mobile-friendly HTML5 arcade game. Steer the ship, dodge rocks, collect coins, and beat your saved high score.

## Test on Android
1. Extract the ZIP.
2. Open `index.html` in a modern browser, or upload the project to a static-hosting service for a quick playable preview.
3. The game saves the best score locally in the browser.

## Preparing for Google Play
This ZIP is the **game source**, not an Android APK or Play Store AAB.
To publish, wrap this HTML5 game in an Android app using a trusted cloud build workflow (for example, a Capacitor-based Android project in a cloud development environment), build a signed Android App Bundle (`.aab`), and test it on your phone.
You will also need a Google Play Console developer account, app listing, privacy/data-safety answers, content rating, app icon, screenshots, and signing setup. Follow the current Google Play Console instructions for target API requirements and testing requirements.
Do not upload the source ZIP as if it were an AAB.
